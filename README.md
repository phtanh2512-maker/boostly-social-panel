# Boostly — Social Media Panel (Demo)

Giao diện SMM Panel bằng HTML/CSS/JavaScript thuần, sẵn sàng triển khai lên GitHub Pages hoặc Vercel.

## Chạy local
Mở `index.html` bằng trình duyệt. Không cần build.

## Deploy Vercel
1. Tạo repository GitHub mới và tải 4 file trong thư mục lên.
2. Trên Vercel chọn **Add New → Project**, import repository.
3. Chọn Framework Preset **Other**.
4. Để trống Build Command và Output Directory rồi nhấn **Deploy**.

## Có trong bản demo
- Dashboard tổng quan và đơn hàng gần đây
- Tạo đơn demo, chọn TikTok / Instagram / Facebook / YouTube
- Bảng dịch vụ có tìm kiếm và lọc
- Lịch sử đơn hàng và trạng thái
- Ví demo, cộng số dư mô phỏng
- Hỗ trợ, hướng dẫn, giao diện tối và responsive mobile

## Giới hạn
Đây là frontend demo: không có đăng nhập, backend, database, cổng thanh toán hoặc nhà cung cấp dịch vụ thật. Đơn hàng và số dư chỉ tồn tại trong bộ nhớ phiên trình duyệt và sẽ mất khi tải lại trang. Giá và dịch vụ chỉ là dữ liệu minh họa, không phải báo giá thực tế. Không nhập mật khẩu mạng xã hội; hãy tuân thủ điều khoản của các nền tảng và chỉ quảng bá tài khoản/nội dung bạn được phép quản lý.
